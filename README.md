# The Pixel Campfire — Arcade Hall

Онлайн-аркадный зал музея The Pixel Campfire: касса, четвертаки,
карусель автоматов, монетка в щель — и 27 ретро-игр в браузере.

## Как это устроено (задумка Юджина, 30.07.2026)

1. **Касса.** Первая страница — стилизованная касса зала. Оплата через
   PayPal: $1 → пригоршня «четвертаков» (номинал обсуждается: quarters
   аутентичнее, nickels щедрее).
2. **Карусель автоматов.** Красивое меню выбора аркад — листаешь зал,
   выбираешь автомат. У каждого — **музейная лекция бесплатно**: табличку
   у экспоната читаешь даром, платишь за «подержать».
3. **Монетка.** Надпись «INSERT COIN», хватаешь четвертак мышкой (на
   таче — свайп), суёшь в приёмник, звяк — игра пошла.
4. **Attract mode.** Пока монет нет — автомат крутит демо за стеклом,
   как в настоящем зале.

## Архитектура

- **Игры:** Kotlin/Wasm + Compose Multiplatform canvas. Исходник игр —
  репо `pixel-classics` (Android, истина), сюда они приезжают
  copy-and-patch порт-скриптом, как в `pixel-classics-desktop`.
  Гейт-вопрос: спайк ОДНОЙ игры в браузере (`spike/`) до постройки зала.
- **Касса:** Go-бэкенд (`server/`), PayPal Orders API v2 + webhook.
  Подробности: [docs/PAYMENTS.md](docs/PAYMENTS.md).
- **Кошелёк:** подписанные токены в куке клиента. Ломается легко —
  но мы и не жадные; подпись отсекает только самых ленивых жуликов.
- **Фронт зала:** статические HTML/CSS/JS (касса, карусель, монетка),
  игры подключаются как wasm-модули на страницу автомата.
