# PKF-Live — The Pixel Campfire Arcade

**Живой зал:** https://elyssov.github.io/PKF-Live/
**Репо на диске:** `C:\projects\pixel-arcade` · **GitHub:** `elyssov/PKF-Live` (Pages деплоит `hall/` на каждый пуш)

Онлайн-аркадный зал музея **The Pixel Campfire**: касса, четвертаки,
карусель автоматов, монетка в щель — и игры музея прямо в браузере.
Третья платформа триады: Google Play (карман) · itch/Windows (стол) ·
**PKF-Live (зал)**.

---

## Идея (Юджин, 30.07.2026)

> Человек заходит на сайт — первая страничка: красиво стилизованная
> касса. Платишь через PayPal доллар — получаешь четвертаки. Дальше —
> зал с каруселью автоматов. Листаешь, выбираешь. «Вставьте четвертак».
> Мышкой хватаешь монетку, суёшь в приёмное окно — игра начинается.
> Музейный текст прилагается бесплатно.

## Ритуал (то, чего не даёт ни один лаунчер)

1. **Касса-вестибюль.** Неон «THE PIXEL CAMPFIRE ARCADE», будка кассира,
   тариф $1 → 4 четвертака. Колокольчик кассы.
2. **Зал.** Карусель одинаковых кабинетов TAVERN TENNIS (единый стиль
   витрины — решение Юджина 31.07); на стекле каждого — скриншот игры,
   поверх мигает INSERT COIN.
3. **Монетка.** Четвертак тащится мышкой из кошелька в щель 25¢ — щель
   подсвечивается, звяк (WebAudio: удар-отскок-качение), монета списана.
4. **Зум.** Трубка со скриншотом плавно (1.4с) раздувается из стекла
   кабинета на весь экран; wasm-игра греется под скриншотом и
   кроссфейдится в живую — переключение незаметно.
5. **Экскурсовод.** Кнопка «🔔 ПОЗВАТЬ ЭКСКУРСОВОДА»: полная музейная
   лекция (те же тексты, что в интро Android-музея) + **аудиолекция
   голосом Лорда Комптона** (Kokoro-82M, генерится локально) — рассказ
   продолжается фоном, пока играешь. Лекции — БЕСПЛАТНО, всегда.
6. **Attract mode** (в бэклоге): пока монеты нет — автомат крутит демо.

## Коммерческая часть (подробно — для Мерси и Киры)

### Продукт и цена

- **Товар — четвертаки** (внутренняя монета зала). Монетка = один запуск
  автомата. Game over = новая монетка (классика зала; continue-политика
  обсуждается — например, 10-секундное окно continue за монетку).
- **Канонический тариф: $1 = 4 четвертака** (25¢ — историческая цена
  запуска, арифметика самой монеты). Обсуждаемые варианты:
  - пачки с бонусом: $5 = 22 монеты, $10 = 48 монет (скидка за объём);
  - «щедрый номинал»: продавать те же запуски как пятицентовики
    ($1 = 20 запусков) — если решим, что четвертак за запуск дорого для
    инди-сборника. Решение за Юджином.
- **Бесплатный слой = маркетинг**: лекции (текст + аудио), витрина,
  attract mode. Читаешь табличку даром — платишь за «подержать».
  Аудиолекции — готовый контент для соцсетей/шортсов (Мерси!).

### Платёжка

- **PayPal Orders API v2** (детали и диаграмма: `docs/PAYMENTS.md`):
  create-order на сервере → покупатель платит в окне PayPal →
  **серверный capture, `status: COMPLETED` = единственный пруф оплаты**
  (редиректу не верим). Sandbox для разработки, webhook
  `PAYMENT.CAPTURE.COMPLETED` как страховка этапа 2.
- **Комиссии PayPal** (стандартный тариф ≈ 3.49% + $0.49 фикс):
  - $1-пачка: комиссия ~$0.52 → нам ~$0.48 (48%!) — терпимо только как
    входной билет;
  - $5-пачка: ~$0.66 → нам ~$4.34 (87%) — **основной SKU**;
  - micropayments-тариф (4.99% + $0.09) выгоднее на мелких — подключить
    в проде, если PayPal одобрит.
- **Кошелёк**: подписанный токен в куке клиента (решение Юджина «без
  выпендрежа»): HMAC-SHA256 серверным секретом + серийник в
  SQLite-леджере против реплея. Ломается умельцем? Пусть: цена запуска —
  четвертак, а лекции и так бесплатны. Мы не жадные — мы атмосферные.
- **Где живёт касса**: Pages статичен → API кассы нужен хостинг
  (вопрос Кире: Go на fly.io/render/VPS; либо v1 вообще без сервера —
  PayPal Smart Buttons + клиентский кошелёк на честном слове).

### Пиратство и защита

wasm исполняется у клиента — утащат при желании. Защита нерентабельна и
не нужна: продаём не бинарь, а **ритуал, зал и голос экскурсовода**.
Похищенная копия без кассы, монетки и лекций — просто голая игра,
т.е. бесплатная реклама.

## Техника (кратко)

- `hall/` — статичный фронт зала (HTML/CSS/JS, ноль зависимостей),
  деплоится на Pages как есть; `hall/games/<id>/` — wasm-дистры игр.
- `spike/` — Kotlin/Wasm + Compose Multiplatform (Kotlin 2.1, CMP 1.7.3);
  дистр ~9.8MB raw (~3MB gzip). Игры музея поедут сюда copy-and-patch
  порт-скриптом, как в `pixel-classics-desktop`.
- `tools/tts_local.py` — озвучка лекций Kokoro-82M локально (CPU, без
  API; модель в `tools/*.onnx`, в гит не входит). HF Inference как
  альтернатива упирается в кредиты аккаунта (см. кэмп 31.07).
- `docs/PAYMENTS.md` — платёжная схема целиком.
